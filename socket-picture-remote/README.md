# socket-picture-remote

Учебный проект: по нажатию кнопки на одном ноутбуке меняется картинка на другом ноутбуке в той же локальной сети. Связь идёт по TCP, окна сделаны на Tkinter, используется только стандартная библиотека Python.

## Файлы

- `server.py` — окно с картинкой и TCP-сервер на порту 5050
- `client.py` — окно с кнопкой «Следующая»
- `pictures/` — картинки в формате `.png`

## Что нужно

Только Python 3. Устанавливать ничего не нужно.

## Проверка на одном ноутбуке

Откройте два терминала в папке проекта. В первом:

```
python server.py
```

Во втором:

```
python client.py
```

Без IP клиент подключается к `127.0.0.1`, то есть к этому же компьютеру.

## Запуск на двух ноутбуках

1. Подключите оба ноутбука к одной сети (надёжнее всего — раздача с телефона).
2. На первом ноутбуке запустите сервер и разрешите доступ в окне брандмауэра:

```
python server.py
```

3. Узнайте IP первого ноутбука командой `ipconfig` (строка «IPv4-адрес»).
4. На втором ноутбуке запустите клиент с этим IP:

```
python client.py 192.168.0.193
```

На второй ноутбук достаточно скопировать `client.py`.

Запускайте через терминал: кнопка Run в VS Code не передаёт IP.

## Если не подключается

Проверьте с ноутбука-клиента, видна ли сеть и открыт ли порт:

```
ping 192.168.0.193
Test-NetConnection 192.168.0.193 -Port 5050
```

- ping не проходит — ноутбуки в разных сетях;
- ping проходит, но `TcpTestSucceeded : False` — брандмауэр на ноутбуке с сервером блокирует Python;
- в консоли клиента «сервер недоступен» — сервер не запущен или указан неверный IP.

## Как работает

1. Клиент при нажатии кнопки подключается по TCP к серверу на порт 5050 и отправляет строку `next`.
2. Сервер ждёт подключения в отдельном потоке и при команде `next` увеличивает номер картинки по кругу.
3. Окно сервера раз в 100 мс через `root.after` проверяет номер и показывает нужную картинку.
