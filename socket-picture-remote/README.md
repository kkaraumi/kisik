# socket-picture-remote.

Учебный проект для переключения картинок на сервере по TCP в локальной сети.
Сервер и клиент используют Tkinter и стандартную библиотеку Python.

## Что нужно

Только Python 3. Устанавливать дополнительные пакеты не нужно.

## Запуск

На первом ноутбуке перейдите в папку проекта и запустите сервер:

python server.py

На втором ноутбуке запустите клиент, указав IP-адрес первого ноутбука:

python client.py 192.168.1.10

Узнать IP-адрес можно командой `ipconfig` в Windows. Найдите IPv4-адрес
подключения к локальной сети.

## Картинки

Сервер показывает файлы `.png` из папки `pictures`. Картинки переключаются
по кругу.

## Если не подключается

Проверьте, что оба ноутбука подключены к одной сети. Разрешите Python
подключаться через брандмауэр Windows и проверьте, что порт `5050` не заблокирован.

## Как работает

Клиент отправляет по TCP строку `next`, сервер получает команду и меняет картинку.
